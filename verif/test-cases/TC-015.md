# TC-015 — Usabilidad del cliente (parcial, Avance 01)

**Requisitos cubiertos en este avance:** RF-17 (ayuda de uso y códigos de salida adecuados), RNF-21 (mensajes de error con operación, causa y acción sugerida).
**Requisito que se completa en H4:** RNF-23 (guía de usuario suficiente sin asistencia; escenarios A, B y E del doc 05).
**Nivel:** sistema. **Hito:** H1.

## Objetivo
Comprobar que el cliente ofrece ayuda, que devuelve 0 en éxito y distinto de 0 en cada tipo de error, y que sus mensajes de error dicen qué operación falló, por qué, y qué hacer.

## Precondiciones
Servicio arrancado según la preparación común para los pasos 5 a 7; **detenido** para el paso 8.

## Entorno y configuración
Preparación común.

## Datos de entrada
Invocaciones del cliente con y sin argumentos, con comando desconocido, con ID inexistente y sin servicio.

## Pasos reproducibles
Después de cada comando ejecutar `echo "codigo: $?"`.
1. `porter --help`
2. `porter` (sin argumentos)
3. `porter volar` (comando desconocido)
4. `porter submit` (falta el comando a ejecutar)
5. `porter status` (falta el ID)
6. `porter submit true` (éxito)
7. `porter status no-existe` (ID inexistente, con servicio arriba)
8. Detener el servicio (Ctrl+C en la terminal 1) y ejecutar `porter list` (sin servicio).

## Resultado esperado
| Paso | Salida | Código |
|---|---|---|
| 1 | Lista los comandos `submit`, `status`, `list`, `cancel` con su uso | 0 |
| 2 | Muestra la ayuda o un error de uso | ≠ 0 (según RF-17, error de uso no es éxito) |
| 3 | Error: comando desconocido, sugiere `--help` | ≠ 0 |
| 4 | Error: falta el comando a ejecutar, muestra el uso correcto | ≠ 0 |
| 5 | Error: falta el ID | ≠ 0 |
| 6 | ID y estado | 0 |
| 7 | Error: el trabajo no existe (`NOT_FOUND`), sugiere `list` para ver los IDs | ≠ 0 |
| 8 | Error: no se pudo conectar con el servicio en host:puerto, sugiere verificar que esté arrancado | ≠ 0 |

Cada mensaje de error de los pasos 3 a 8 debe indicar **operación, causa y acción sugerida** (RNF-21).
