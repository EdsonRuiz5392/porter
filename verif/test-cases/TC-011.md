# TC-011 — Restricción de red

**Requisitos cubiertos:** RF-20, RNF-12, RNF-13.
**Nivel:** sistema. **Hito:** H3.

## Objetivo
Comprobar que solo se aceptan conexiones de las redes permitidas, que los rechazos se registran sin revelar la configuración, y que una configuración de red peligrosa o mal escrita impide arrancar.

## Precondiciones
Servicio reiniciado con la configuración de abajo y `/tmp/porter-tc` limpio, según la [preparación común](README.md).

## Entorno y configuración
- **Automatizado:** un solo equipo. `127.0.0.3` hace de equipo autorizado y `127.0.0.9` de equipo no autorizado.
- **Demostración entre dos equipos:** un equipo que esté en el hotspot o la VPN pero fuera de `JOBRUNNER_ALLOWED_NETWORKS`.

## Datos de entrada
- `JOBRUNNER_ALLOWED_NETWORKS`: `127.0.0.1,127.0.0.3`, `127.0.0.0/30` y sin configurar.
- Configuraciones inválidas: `10.0.0.0/33`, `127.0.0.1,mi-casa`, `0.0.0.0/0`, `8.8.8.0/24`, `" , "`, `JOBRUNNER_HOST=8.8.8.8` y `JOBRUNNER_HOST=servidor-casa`.

## Pasos reproducibles
**Automatizado:**

```bash
python3 verif/scripts/run_verificacion.py --filtro tc011
```

**A mano:**

1. Desde un equipo no autorizado: `porter --host <IP del servidor> submit echo "no debo correr"`.
2. Revisar que no se creó el trabajo (`porter list` desde el servidor) y buscar `ACCESS_DENIED` en la bitácora.
3. Conectarse sin mandar nada (`nc <IP> <puerto>`) y revisar la bitácora.
4. Arrancar el servicio con cada configuración inválida y anotar el código de salida y el mensaje.
5. Arrancar con `JOBRUNNER_HOST=0.0.0.0` y buscar `BIND_ALL_INTERFACES`.

## Resultado esperado
- El equipo no autorizado recibe `ACCESS_DENIED`; el mensaje no muestra las redes permitidas.
- No se crea ningún trabajo, la bitácora registra la dirección rechazada y el servicio sigue atendiendo a los autorizados.
- Conectarse sin mandar nada también se rechaza y se registra.
- La notación CIDR se respeta: con `127.0.0.0/30` entran `.1` a `.3` y no `.5` ni `.200`.
- Sin configurar nada, el servicio escucha solo en `127.0.0.1` y solo acepta localhost.
- Con cada configuración inválida no arranca, termina con código distinto de 0 y muestra `Configuración inválida`.
- `0.0.0.0` se permite, pero queda registrado como advertencia (`BIND_ALL_INTERFACES`).
