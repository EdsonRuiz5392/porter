# TC-023 — Compatibilidad de protocolo

**Requisitos cubiertos:** RNF-32.
**Nivel:** integración. **Hito:** H2 (local) · H3.

## Objetivo
Comprobar que un mensaje con una versión incompatible se rechaza de forma explícita.

## Precondiciones
Servicio reiniciado con la configuración de abajo y `/tmp/porter-tc` limpio, según la [preparación común](README.md).

## Entorno y configuración
Preparación común, con Valores por defecto.

## Datos de entrada
`version` igual a `99`, ausente y `"1"`.

## Pasos reproducibles
**Automatizado:**

```bash
python3 verif/scripts/run_verificacion.py --filtro tc023
```

**A mano:**

1. Con un cliente de prueba, enviar `list` con cada versión.
2. Enviar `list` con `version: 1`.

## Resultado esperado
- Cada versión incompatible recibe `error` con `VERSION_UNSUPPORTED`.
- La versión 1 recibe `list_response` y el servicio sigue atendiendo.
