# TC-021 — Escalamiento de la cancelación

**Requisitos cubiertos:** RF-30.
**Nivel:** robustez. **Hito:** H2.

## Objetivo
Comprobar que un trabajo que ignora SIGTERM recibe SIGKILL después del tiempo de gracia.

## Precondiciones
Servicio reiniciado con la configuración de abajo y `/tmp/porter-tc` limpio, según la [preparación común](README.md).

## Entorno y configuración
Preparación común, con `JOBRUNNER_GRACE_SECONDS=2`.

## Datos de entrada
`bash -c "trap '' TERM; sleep 30"`.

## Pasos reproducibles
**Automatizado:**

```bash
python3 verif/scripts/run_verificacion.py --filtro tc021
```

**A mano:**

1. `porter submit bash -c "trap '' TERM; sleep 30"` y esperar `RUNNING`.
2. `porter cancel <ID>` y medir hasta que cambie el estado.
3. `porter status <ID>`, `pgrep -f 'sleep 30'` y revisar la salida del servicio.

## Resultado esperado
- Queda `CANCELED` con código `-9`.
- Pasan entre 1.8 y 5 segundos.
- La salida del servicio contiene `Escalando a SIGKILL`.
- No quedan procesos.
