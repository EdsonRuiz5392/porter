Me ayudó a interpretar el documento de flujo del equipo (orden de los pull requests, dependencias entre ellos y qué Issues se cierran con cada uno), a ejecutar los comandos de Git (crear ramas, git status, commit, push, git pull, git log), a redactar los títulos y descripciones de los pull requests a partir de la plantilla del documento, y a resolver dudas sobre la diferencia entre Refs y Closes y la vinculación de los Issues en GitHub.

El código de mi parte lo desarrollé yo, y las decisiones finales sobre el proyecto las tomé junto con mi equipo.
